=====================================================================
            ISHAN SINGLISH - 100% STANDALONE CONVERTER APP
=====================================================================

This web application is 100% self-contained and works on ANY computer 
without internet, background servers, or special software!

HOW TO RUN:
1. Double-click "index.html" (or "Open_Converter.bat").
2. It opens instantly in your default web browser (Chrome, Edge, Firefox).

PORTABILITY:
You can copy this entire folder ("singlish") to a USB flash drive, 
another PC, or smartphone, and it will work completely offline.

FILES IN THIS FOLDER:
- index.html           : Main Ishan Singlish web page
- styles.css           : Offline styling (Light/Dark themes)
- singlish-converter.js: Singlish & English conversion engine
- app.js               : UI controller, audio, font selector & history
- Open_Converter.bat   : One-click launcher for Windows

KEY FEATURES:
✔ 100% Offline (No internet or external servers needed)
✔ Real-time Singlish to Sinhala conversion (Helakuru & UCSC modes)
✔ Offline English-to-Sinhala Dictionary Converter
✔ Mixed English & Sinhala Output (quote-free preservation)
✔ Typing Sound Effects (Web Audio API)
✔ Installed Computer Font Selector
✔ Bold & Font Size Controls
✔ Light / Dark Mode Toggle
✔ Local Storage History
